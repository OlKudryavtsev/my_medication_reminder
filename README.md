# MedKid Bot — Telegram-бот и Mini App для приема лекарств

Проект для Railway: Telegram-бот (`aiogram`) + Mini App/API (`FastAPI`) + PostgreSQL.

## Что есть в версии v3

- стартовое расписание без Фитомуцила;
- роли: `parent`, `child`, `unknown`;
- все функции закрыты для `unknown`-пользователей, кроме `/start`;
- напоминания ребенку и родителям до отметки;
- кнопки в напоминаниях: `Выпил(а)`, `Отложить 30 мин`, `Пропущено`, `Сегодня`;
- исправлена кнопка `Сегодня` в уведомлениях: расписание отправляется напрямую пользователю, который нажал кнопку;
- при отметке `Выпил(а)` можно указать фактическое время;
- фактическое время можно изменить позже в Mini App или через кнопку `Изменить время приема` в боте;
- даты начала и окончания лечения по каждой строке расписания;
- история и статистика по препаратам;
- родительское администрирование расписания в Mini App;
- редактирование текущего расписания в админке;
- нижняя навигация Mini App: `Сегодня`, `Статистика`, `История`, `Админ`;
- светлая/темная тема с переключателем сверху справа;
- адаптированный минималистичный интерфейс для iPhone;
- 200 коротких юмористических сообщений для напоминаний и 200 благодарственных сообщений.

## Переменные окружения Railway

```env
BOT_TOKEN=токен_бота_от_BotFather
DATABASE_URL=${{Postgres.DATABASE_URL}}
APP_BASE_URL=https://ваш-домен.up.railway.app
PARENT_CHAT_IDS=111111111,222222222
CHILD_CHAT_ID=333333333
TIMEZONE=Europe/Berlin
REMINDER_INTERVAL_MINUTES=7
SNOOZE_MINUTES=30
ALLOW_DEV_INITDATA=false
DEFAULT_BREAKFAST_TIME=08:00
DEFAULT_LUNCH_TIME=13:30
DEFAULT_DINNER_TIME=19:30
```

`ALLOW_DEV_INITDATA=false` рекомендуется для Railway. Если нужно тестировать Mini App в обычном браузере, временно поставьте `true`, но для production верните `false`.

## Обновление уже работающего Railway-проекта

1. Распакуйте архив v3.
2. Замените файлы в текущем GitLab/GitHub-проекте.
3. Запушьте изменения:

```bash
git add .

```

4. Railway автоматически пересоберет сервис.
5. Проверьте переменные `SNOOZE_MINUTES` и `ALLOW_DEV_INITDATA`.
6. Если нужно пересоздать стартовое расписание без Фитомуцила, родитель должен выполнить в Telegram:

## Как пользоваться

### Ребенок

- получает напоминания;
- может нажать `Выпил(а)`, выбрать фактическое время, отложить на 30 минут или отметить пропуск;
- видит вкладки `Сегодня`, `Статистика`, `История`;
- не видит вкладку `Админ`.

### Родители

- получают напоминания и уведомления о действиях ребенка;
- могут отмечать прием, пропуск и отложить прием;
- имеют доступ к `Администрированию`;
- могут добавлять, редактировать и отключать строки расписания;
- могут смотреть статистику и историю по каждому препарату.

### Unknown-пользователи

Если пользователь не указан в `CHILD_CHAT_ID` или `PARENT_CHAT_IDS`, ему доступна только команда `/start`. Бот покажет его Telegram ID, который нужно добавить в Railway Variables.

## Администрирование расписания

Откройте Mini App и перейдите во вкладку `Админ` в нижней панели.

Можно:

- добавить препарат;
- указать дозу;
- указать время приема;
- указать комментарий, например `за 30 мин до еды`;
- указать дату начала курса;
- указать дату окончания курса;
- изменить любую существующую строку расписания;
- отключить строку расписания.

При редактировании расписания будущие `pending`-события по этой строке пересоздаются по новому времени и датам. Уже принятые или пропущенные события остаются в истории.

## Фактическое время приема

В Mini App на вкладке `Сегодня`:

- для ожидающего приема выберите время и нажмите `Выпил`;
- для уже принятого приема измените время и нажмите `Изменить время`.

В Telegram после нажатия `Выпил(а)` бот спрашивает время: `Сейчас`, `По расписанию` или `Ввести время`. После отметки появляется кнопка `Изменить время приема`.

## Важные замечания

- Бот работает через polling, webhook не нужен.
- Railway должен иметь один app-сервис и отдельный PostgreSQL-сервис.
- Telegram-бот не может сам написать пользователю, пока пользователь первым не отправил `/start`.
- Если родитель не видит `Админ`, проверьте, что его Telegram ID указан в `PARENT_CHAT_IDS`, а сервис был перезапущен после изменения переменных.

## Изменения v5 — правки интерфейса Mini App

- На вкладке **Сегодня** у непринятых приемов теперь только 3 действия: **Выпил**, **+30 мин**, **Пропустил**.
- У принятых приемов отображается статус и фактическое время; изменение времени открывается отдельной кнопкой **Изменить время**.

- Вкладка **Админ** переработана:
  - в блоке **Добавить прием** каждая строка содержит один параметр и одно поле;
  - даты начала и окончания находятся в одной строке;
  - в **Текущем расписании** поля по умолчанию только для чтения;
  - кнопка **Изменить** переводит строку в режим редактирования;
  - в режиме редактирования появляются кнопки **Сохранить** и **Отменить**;
  - кнопка **Отключить** переименована в **Удалить**;

## Версия v12 — групповые напоминания

Если на одно и то же время запланировано несколько лекарств, бот теперь отправляет одно общее напоминание вместо нескольких отдельных сообщений.

Пример: если в 08:00 нужно принять Панкреатин, Баксет и Атоминекс, придет одно сообщение со списком препаратов и групповыми кнопками:

- ✅ Выпили все
- 😴 Отложить все 30 мин
- ⏭️ Пропущено все
- 📋 Сегодня

Групповая отметка применяет выбранное действие ко всем непринятым препаратам с этим временем приема. Если в группе часть лекарств уже была отмечена, действие применится только к оставшимся `pending`-событиям.

## v13: исправление APP_BASE_URL

Если в Railway переменная `APP_BASE_URL` указана без `https://`, Telegram отклоняет WebApp-кнопку с ошибкой `Only HTTPS links are allowed`. Начиная с v13 приложение само нормализует URL:

- `mymedicationreminder-production.up.railway.app` превратится в `https://mymedicationreminder-production.up.railway.app/app`;
- `https://mymedicationreminder-production.up.railway.app` превратится в `https://mymedicationreminder-production.up.railway.app/app`;
- `https://mymedicationreminder-production.up.railway.app/app` останется как есть.

Рекомендуемое значение Railway Variables:

```env
APP_BASE_URL=https://mymedicationreminder-production.up.railway.app
```

Не добавляйте лишний `/app`, хотя v13 умеет корректно обработать и такой вариант.
