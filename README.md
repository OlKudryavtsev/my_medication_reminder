# MedKid Telegram Bot v30

## Что изменено в v30

1. Логика приведена к модели: **Назначение → курсы лекарств → активное расписание**.
2. Вкладка **Лекарства** переименована в **Расписание**.
3. Добавление лекарств перенесено в **Админ → Назначения**: внутри каждого назначения теперь добавляются курсы лекарств.
4. Для курса лекарства показываются:
   - дата начала / окончания;
   - схема приема;
   - нужно на курс;
   - осталось нужно с учетом фактически принятых доз;
   - остаток в аптечке;
   - хватает / не хватает.
5. Курс лекарства становится активным и попадает в расписание:
   - автоматически, если указана дата начала сегодня или раньше;
   - вручную по кнопке **Начать курс**, если курс еще не активен.
6. В одном назначении одно лекарство можно добавить только один раз. Если препарат принимается несколько раз в день, это считается одним курсом лекарства с несколькими приемами.
7. Вкладка **Расписание** показывает только активное расписание. Потребность по курсу там больше не отображается.
8. ИИ-помощник из текста перенесен в **Назначения**: у каждого назначения есть кнопка **ИИ из текста**.
