# Семейная аптечка — v29

Telegram-бот + Mini App для контроля приема лекарств, назначений врача, аптечки, профилей ребенка/родителя, уведомлений, AI-распознавания назначений и учета потребности лекарств на курс.

## Что изменено в v29

1. В `Админ → Лекарства → Текущее расписание → Изменить` добавлено поле `Назначение`.
   Теперь уже созданный прием/лекарство можно привязать к назначению без удаления и повторного создания.

2. Убрана ручная привязка лекарства к позиции аптечки из формы лекарства.
   Аптечка и так создается по списку лекарств из вкладки `Лекарства`, поэтому связь определяется автоматически по `medicine_id`/названию.

3. Убраны поля `Списывать за прием` и `Ед. списания` из интерфейса.
   Теперь расчет потребности и списание из аптечки берутся из поля `Доза`.
   Примеры: `1 таб`, `0.5 таб`, `2 капс`, `5 мл`, `1 пакет`.

4. Потребность лекарства на курс теперь отображается:
   - в `Админ → Назначения` внутри карточки назначения, по всем привязанным лекарствам;
   - в `Админ → Лекарства → Текущее расписание` внутри каждой строки лекарства.

5. В карточках показывается:
   - сколько нужно на курс/период;
   - сколько уже принято;
   - сколько еще нужно;
   - сколько есть в аптечке;
   - сколько не хватает.

## Важная логика

- `Лекарство` — это препарат/строка расписания с дозой, частотой и датами приема.
- `Назначение` — документ/визит врача.
- Уже добавленное лекарство можно привязать к назначению через редактирование текущего расписания.
- Аптечка связывается автоматически с лекарствами из расписания по `medicine_id`/названию.
- Расчет потребности идет из `Доза`, даты начала/окончания и периодичности.
