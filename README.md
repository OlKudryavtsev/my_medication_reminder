# Семейная аптечка — v26

Telegram-бот + Mini App для напоминаний о лекарствах, профилей семьи, назначений, расписания, аптечки, истории и отчетов.

## Что нового в v21

1. Тревога родителям при просрочке приема: если прием не отмечен дольше `OVERDUE_ALERT_MINUTES`, родителям приходит отдельное предупреждение.
2. Уведомление о пропуске: если ребенок/пользователь отмечает прием как пропущенный, родителям отправляется сообщение.
3. Вечерний итог дня в 23:45: принято / пропущено / не отмечено / всего по каждому профилю.
4. Вкладка **Админ → Аптечка**: учет остатков лекарств, единицы измерения, порог напоминания, фото лекарства.
5. Напоминание о покупке: если остаток меньше или равен порогу, родителям приходит сообщение о покупке. Для личного профиля родителя уведомление приходит только владельцу профиля.
6. Отчет для врача: экспорт PDF и Excel за 30 дней.
7. Поиск по имени лекарства на вкладках **Лекарства** и **Аптечка**.

## Обновление на Railway


Новые переменные окружения необязательны, есть значения по умолчанию:

```env

```

После деплоя полностью закройте Mini App в Telegram и откройте заново через `/app`.

## Важные замечания

- Остатки в аптечке уменьшаются на 1 единицу при отметке приема как `Принято`, если в аптечке есть активная запись с таким же названием лекарства.
- Напоминание о покупке отправляется не чаще одного раза в день по одной позиции, пока остаток не станет выше порога.
- PDF/Excel формируются по текущему выбранному профилю.

## v26 — OpenAI / ИИ-помощник

Добавлены AI-функции, которые работают только если заданы переменные Railway:

```env
OPENAI_ENABLED=true
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4o-mini
```

Что появилось:

1. **Добавить лекарство с помощью ИИ**  
   В `Админ → Лекарства → Добавить лекарство` есть поле `Текст назначения`. Можно написать фразу вроде:

   ```text
   Панкреатин 1 капсула во время еды 3 раза в день с 10 по 20 июня
   ```

   ИИ заполнит форму черновиком. Перед сохранением данные обязательно нужно проверить вручную.

2. **Распознать назначение по фото**  
   В форме добавления лекарства можно приложить фото назначения. ИИ попытается извлечь препараты, дозы, частоту и привязку к еде. Приложение покажет черновик, а не будет автоматически создавать лечение.

3. **Распознать упаковку лекарства для Аптечки**  
   В `Админ → Аптечка → Добавить в аптечку` можно выбрать фото и нажать `Распознать название по фото`. ИИ заполнит название/единицу измерения, если смог распознать.

4. **Черновик отчета для врача**  
   На вкладке `Статистика` добавлен блок `ИИ-черновик отчета для врача`. Он делает текстовое резюме по фактической статистике и событиям за выбранный период.

Важно: ИИ не назначает лечение, не меняет дозировки и не должен использоваться как замена врачу. Все распознанные данные показываются как черновик и требуют проверки родителем.

## v27 — распознавание назначения как списка препаратов

Добавлена отдельная AI-функция в `Админ → Назначения`:

1. Кнопка **Распознать назначение**.
2. После загрузки фото назначения приложение показывает три блока:
   - **Общие данные назначения**: название, дата назначения, врач, комментарий.
   - **Распознанные лекарства**: список препаратов с дозами, частотой, датами и привязкой ко времени еды.
   - **Действия**: создать назначение и добавить выбранные лекарства, сохранить только назначение или отменить.
3. Назначение врача теперь обрабатывается как контейнер, внутри которого может быть несколько лекарств с разными сроками приема.
4. Фото назначения прикладывается к созданному назначению.
5. Каждый распознанный препарат можно перенести в обычную форму добавления лекарства кнопкой **В форму** для ручной правки.

Переменные Railway для AI остаются прежними:

## v28 — связь назначений, лекарств и аптечки

Добавлено:

- у каждой строки расписания можно выбрать назначение;
- уже добавленные лекарства можно привязать к назначению через `Админ → Лекарства → Текущее расписание → Изменить`;
- строку лекарства можно явно связать с позицией аптечки;
- добавлены поля `Списывать за прием` и `Ед. списания`;
- приложение рассчитывает потребность на курс: сколько приемов запланировано и сколько единиц лекарства потребуется;
- в текущем расписании показывается сравнение с аптечкой: сколько нужно, сколько осталось нужно, сколько есть в аптечке и дефицит;
- при отметке `Принято` списание из аптечки теперь идет по настройке строки лекарства, а не всегда по 1;
- миграции БД выполняются автоматически при старте.

Новые поля в таблице `schedules`:

```text
inventory_item_id
consume_units_per_dose
consume_unit_name
planned_doses_count
planned_units_total
```
