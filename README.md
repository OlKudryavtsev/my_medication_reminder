# MedKid Telegram Bot + Mini App

Семейный Telegram-бот и Telegram Mini App для контроля приема лекарств ребенком.

> Важно: приложение не дает медицинских рекомендаций и не заменяет врача. Оно только помогает соблюдать назначенный врачом график.

## Что изменено в этой версии

1. Из стартового расписания удален `Фитомуцил`.
2. В напоминания добавлены кнопки:
   - `✅ Выпил(а)`;
   - `😴 Отложить 30 мин`;
   - `⏭️ Пропущено`;
   - `📋 Сегодня`.
3. Добавлен режим отложенного напоминания на 30 минут.
4. Добавлен родительский раздел `⚙️ Администрирование` в Mini App.
5. Пользователям с ролью `unknown` запрещены все функции, кроме `/start` для просмотра своего Telegram ID.
6. В расписании можно указывать дату начала и дату окончания лечения.
7. При отметке `Выпил(а)` можно указать фактическое время приема.
8. Добавлены история и статистика по каждому препарату.
9. Добавлена мягкая миграция БД: при деплое в существующую Railway PostgreSQL база сама получит новые колонки.

## 1. Создание Telegram-бота

1. Откройте Telegram и найдите `@BotFather`.
2. Выполните `/newbot`.
3. Задайте имя, например `Семейная аптечка`.
4. Задайте username, например `my_family_meds_bot`.
5. Скопируйте токен вида `123456:ABC...` — это `BOT_TOKEN`.
6. После деплоя выполните у BotFather:
   - `/setmenubutton` → выберите бота → укажите URL мини-приложения Railway: `https://...railway.app/app`;
   - `/setcommands` → выберите бота → вставьте:

```text
start - запуск и регистрация
today - расписание на сегодня
app - открыть мини-приложение
admin - администрирование расписания для родителей
stats - статистика за 30 дней
history - история по препарату
add - добавить прием лекарства
seed_schedule - пересоздать стартовое расписание
help - помощь
```

## 2. Переменные окружения Railway

Минимально нужны:

```env
BOT_TOKEN=токен_от_BotFather
DATABASE_URL=${{Postgres.DATABASE_URL}}
APP_BASE_URL=https://ваш-домен.up.railway.app
PARENT_CHAT_IDS=111111111,222222222
CHILD_CHAT_ID=333333333
TIMEZONE=Europe/Berlin
REMINDER_INTERVAL_MINUTES=7
SNOOZE_MINUTES=30
ALLOW_DEV_INITDATA=false
DEFAULT_BREAKFAST_TIME=08:00
DEFAULT_LUNCH_TIME=13:30
DEFAULT_DINNER_TIME=19:30
```

Чтобы узнать Telegram ID родителей и ребенка:

1. Временно запустите бота только с `BOT_TOKEN`.
2. С каждого аккаунта напишите боту `/start`.
3. Бот покажет Telegram ID.
4. Добавьте ID ребенка в `CHILD_CHAT_ID`.
5. Добавьте ID родителей в `PARENT_CHAT_IDS` через запятую.
6. Перезапустите сервис.

## 3. Роли и доступы

### Parent

Родитель может:

- смотреть расписание на сегодня;
- отмечать прием как принятый;
- указывать фактическое время приема;
- отмечать пропуск;
- откладывать напоминание на 30 минут;
- смотреть историю и статистику;
- открывать раздел администрирования;
- добавлять новые препараты в расписание;
- отключать строки расписания;
- пересоздавать стартовое расписание командой `/seed_schedule`.

### Child

Ребенок может:

- смотреть расписание на сегодня;
- отмечать прием как принятый;
- указывать фактическое время приема;
- отмечать пропуск;
- откладывать напоминание на 30 минут;
- смотреть историю и статистику.

Ребенку недоступно администрирование расписания.

### Unknown

Любой пользователь, чей Telegram ID не указан в `CHILD_CHAT_ID` или `PARENT_CHAT_IDS`, может выполнить только `/start`, чтобы узнать свой ID. Все остальные функции запрещены.

## 4. Локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# заполните BOT_TOKEN, CHILD_CHAT_ID, PARENT_CHAT_IDS
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Откройте `http://localhost:8000/health`.

Для локальной проверки Mini App в обычном браузере можно временно поставить:

```env
ALLOW_DEV_INITDATA=true
```

На Railway лучше оставить:

```env
ALLOW_DEV_INITDATA=false
```

## 5. Деплой на Railway через GitLab/GitHub

1. Распакуйте архив проекта.
2. Создайте новый GitLab-проект или GitHub-репозиторий.
3. Загрузите туда файлы проекта.
4. В Railway создайте `New Project`.
5. Выберите деплой из репозитория.
6. В этом же Railway-проекте добавьте PostgreSQL database.
7. В сервисе приложения откройте `Variables` и добавьте переменные из раздела 2.
8. Убедитесь, что `DATABASE_URL` доступна сервису приложения.
9. Railway соберет приложение по `Dockerfile`. Start command задавать не нужно.
10. Откройте `/health` на публичном домене. Должно быть:

```json
{"status":"ok"}
```

11. Напишите боту `/start`, затем `/today`.
12. В BotFather настройте кнопку мини-приложения на:

```text
https://ваш-домен.up.railway.app/app
```

## 6. Обновление уже работающего бота

Если бот уже был развернут предыдущей версией:

1. Замените код в GitLab/GitHub на новую версию.
2. Сделайте `git push`.
3. Railway пересоберет и перезапустит сервис.
4. При старте приложение выполнит мягкую миграцию БД и добавит новые колонки:
   - `schedules.start_date`;
   - `schedules.end_date`;
   - `dose_events.skipped_at`;
   - `dose_events.skipped_by`;
   - `dose_events.postponed_until`.
5. Чтобы удалить Фитомуцил из уже существующего расписания, выполните в Telegram от родителя:

```text
/seed_schedule
```

Команда пересоздаст стартовое расписание без Фитомуцила. Важно: она удаляет старые лекарства, расписание и события приема, затем создает стартовый набор заново.

## 7. Использование в Telegram

### `/today`

Показывает расписание на сегодня.

Статусы:

- `⏳` — ожидает отметки;
- `✅` — принято;
- `⏭️` — пропущено;
- `😴` — отложено.

### Напоминания

Когда наступает время приема, бот отправляет ребенку и родителям юмористическое напоминание с кнопками:

- `✅ Выпил(а)`;
- `😴 Отложить 30 мин`;
- `⏭️ Пропущено`;
- `📋 Сегодня`.

Если прием остается в статусе `pending`, повтор идет каждые `REMINDER_INTERVAL_MINUTES` минут.

Если нажать `Отложить 30 мин`, бот не будет напоминать до времени `now + SNOOZE_MINUTES`.

### Отметка `Выпил(а)`

После нажатия `✅ Выпил(а)` бот спросит фактическое время:

- `Сейчас: HH:MM`;
- `По расписанию: HH:MM`;
- `Ввести время`.

Если выбрать `Ввести время`, нужно отправить время в формате:

```text
08:17
```

Родители получат уведомление с фактическим временем.

### `Пропущено`

Кнопка переводит прием в статус `skipped`. Родители получают уведомление о пропуске.

### `/stats`

Показывает статистику за 30 дней по каждому препарату:

- сколько принято;
- сколько пропущено;
- сколько еще ожидает;
- процент принятых.

### `/history`

Показывает список препаратов. После выбора препарата бот выводит историю за 30 дней.

## 8. Использование Mini App

Откройте командой:

```text
/app
```

В Mini App доступны вкладки:

- `Сегодня`;
- `Статистика`;
- `История`;
- `Администрирование` — только для родителей.

Во вкладке `Сегодня` можно:

- указать фактическое время приема;
- нажать `Выпил`;
- нажать `Отложить 30 мин`;
- нажать `Пропущено`.

Во вкладке `Администрирование` родитель может:

- добавить препарат;
- указать дозу;
- указать время;
- указать комментарий;
- указать дату начала лечения;
- указать дату окончания лечения;
- отключить строку расписания.

## 9. Добавление приема через Telegram

Доступно только родителям.

Формат:

```text
/add Название | Доза | HH:MM | Комментарий | YYYY-MM-DD | YYYY-MM-DD
```

Пример с датами курса:

```text
/add Аквадетрим | 2 капли | 09:00 | после завтрака | 2026-06-06 | 2026-06-20
```

Пример без даты окончания:

```text
/add Аквадетрим | 2 капли | 09:00 | после завтрака | 2026-06-06 |
```

## 10. Стартовое расписание без Фитомуцила

В проект внесено расписание:

### Утро

За 30 минут до завтрака:

- Гимекромон — 1 таб;
- Тримедат — 1 таб.

Во время завтрака:

- Панкреатин — 1 капс;
- Баксет — 1 капс;
- Атоминекс — 1 капсула.

Сразу после завтрака:

- Аскорутин — 1 таб.

### День

За 30 минут до обеда:

- Гимекромон — 1 таб;
- Тримедат — 1 таб.

Во время обеда:

- Панкреатин — 1 капс.

Сразу после обеда:

- Аскорутин — 1 таб.

В 17:30:

- Феварин — 1 таблетка.

### Вечер

За 30 минут до ужина:

- Гимекромон — 1 таб;
- Тримедат — 1 таб.

Во время ужина:

- Панкреатин — 1 капс.

Сразу после ужина:

- Аскорутин — 1 таб.

В 23:15:

- Феварин — 1 таблетка.

Время завтрака/обеда/ужина задается переменными:

```env
DEFAULT_BREAKFAST_TIME=08:00
DEFAULT_LUNCH_TIME=13:30
DEFAULT_DINNER_TIME=19:30
```

Для «сразу после еды» используется `+10 минут` от времени еды.

## 11. Ограничения текущей версии

- Расписание ежедневное: нет выбора дней недели.
- Отключение расписания не удаляет историю старых событий.
- Нет отдельного экрана редактирования уже созданной строки расписания; можно отключить и добавить новую.
- Нет экспорта отчета в файл.
- Нет медицинской проверки взаимодействий препаратов.
