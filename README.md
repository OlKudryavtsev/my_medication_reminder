# Семейная аптечка — v34

## Что изменено в v34

1. Исправлено редактирование курса лекарства в назначении: при изменении периодичности, например с `1 раз в день` на `3 раза в день`, курс пересоздается корректно с нужным количеством приемов.
2. Секция **Распознать назначение** на вкладке **Назначения** скрыта по умолчанию и раскрывается по кнопке. Дизайн секции сделан более аккуратным.
3. Карточки курсов в назначении переработаны:
   - по умолчанию виден только заголовок курса;
   - заголовок содержит препарат и длительность приема;
   - при раскрытии отображаются формат, доза, способ применения, периодичность, шаблон приема, аналоги, расчет потребности и связь с аптечкой.
4. В курс лекарства добавлены поля:
   - формат;
   - способ применения;
   - аналоги из назначения.
5. Вкладка **Расписание** визуально обновлена. Для приемов, привязанных к еде, отображается не техническое время, а `Завтрак`, `Обед`, `Ужин` с шаблоном приема.
6. В редактировании строки расписания снова доступна привязка к назначению.
7. Удаление строки расписания теперь удаляет запись полностью, а не просто скрывает ее, чтобы редактирование группы курсов не оставляло старые дубли.
8. AI-промпт дополнен полями `dosage_form`, `administration_route`, `analogs` для распознавания назначений врача.

## v35

Изменения:
- Исправлен скролл модального окна редактирования курса лекарства на iPhone.
- В курс лекарства добавлена длительность: дни / недели / месяцы. Если указана дата начала и длительность, дата окончания рассчитывается автоматически при сохранении/старте курса.
- Карточка курса лекарства перестроена под модель назначения: препарат, формат, дозировка, периодичность, способ применения, длительность, аналоги, расчет потребности и остаток аптечки.
- Поля «Способ» и «Прием» разведены по смыслу: «Периодичность/Прием» — когда принимать, «Способ применения» — как принимать.
- Вкладка «Расписание» показывает только активное расписание: время/слот приема, препарат, назначение и курс. Детали раскрываются по нажатию.
- Добавлена группировка расписания по назначению с переключателем вверху.

## v38

UI/UX доработки:
- раскрытие/сворачивание конкретного назначения теперь выполняется локально, без полной перезагрузки вкладки;
- раскрытый курс лекарства отображается компактным списком параметров `поле — значение`, без двухколоночных больших плиток;
- вкладка `Расписание` получила компактную панель управления: группировка/список и раскрыть/скрыть группы в одну строку;
- карточки расписания приведены визуально ближе к вкладке `Сегодня`.

## v39 — Ввод исторических приемов по дням

Добавлено:

- в карточке курса лекарства появилась кнопка **Внести историю**;
- можно выбрать период `Дата с` / `Дата по`;
- приложение строит таблицу по дням и приемам курса;
- по каждой ячейке можно выбрать статус: `Не менять`, `Принято`, `Пропущено`, `Не принято`;
- есть массовое заполнение таблицы выбранным статусом;
- режимы безопасности при уже существующих событиях:
  - `Не перезаписывать`;
  - `Перезаписать только неотмеченные`;
  - `Перезаписать все`;
- есть отдельный флаг учета аптечки: по умолчанию исторический ввод **не списывает** остатки;
- добавлены API:
  - `GET /api/medicine-courses/{id}/history-grid`;
  - `POST /api/medicine-courses/{id}/history-grid`.

Рекомендация: при внесении старых приемов до запуска бота оставляйте `Аптечка = Не списывать`, чтобы не исказить текущие остатки.
