# MedKid Telegram Bot + Mini App

MVP семейного Telegram-бота для контроля приема лекарств ребенком:

- расписание лекарств;
- повторные напоминания ребенку и родителям до отметки;
- кнопка `✅ Выпил(а)` прямо в Telegram;
- Telegram Mini App со списком приемов на сегодня;
- добавление новых приемов из Mini App или командой `/add`;
- уведомление родителей после отметки приема;
- стартовое расписание из ТЗ уже зашито в проект.

> Важно: приложение не дает медицинских рекомендаций и не заменяет врача. Оно только помогает соблюдать назначенный график.

## 1. Создание Telegram-бота

1. Откройте Telegram и найдите `@BotFather`.
2. Выполните `/newbot`.
3. Задайте имя, например `Семейная аптечка`.
4. Задайте username, например `my_family_meds_bot`.
5. Скопируйте токен вида `123456:ABC...` — это `BOT_TOKEN`.
6. После деплоя выполните у BotFather:
   - `/setmenubutton` → выберите бота → укажите URL мини-приложения Railway: `https://...railway.app/app`;
   - `/setcommands` → выберите бота → вставьте:

```text
start - запуск и регистрация
today - расписание на сегодня
app - открыть мини-приложение
add - добавить прием лекарства
seed_schedule - пересоздать стартовое расписание
help - помощь
```

## 2. Переменные окружения

Минимально нужны:

```env
BOT_TOKEN=токен_от_BotFather
DATABASE_URL=postgresql://...  # Railway добавит после подключения Postgres
APP_BASE_URL=https://ваш-домен.up.railway.app
PARENT_CHAT_IDS=111111111,222222222
CHILD_CHAT_ID=333333333
TIMEZONE=Europe/Berlin
REMINDER_INTERVAL_MINUTES=7
DEFAULT_BREAKFAST_TIME=08:00
DEFAULT_LUNCH_TIME=13:30
DEFAULT_DINNER_TIME=19:30
```

Чтобы узнать Telegram ID родителей и ребенка, сначала можно запустить бота только с `BOT_TOKEN`, написать ему `/start` с каждого аккаунта, посмотреть ID в ответе и затем заполнить `PARENT_CHAT_IDS` и `CHILD_CHAT_ID`.

## 3. Локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# заполните BOT_TOKEN
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Откройте `http://localhost:8000/health`.

## 4. Деплой на Railway через GitHub

1. Распакуйте архив проекта.
2. Создайте новый GitHub-репозиторий и загрузите туда файлы.
3. В Railway: `New Project` → `Deploy from GitHub repo` → выберите репозиторий.
4. В этом же проекте Railway добавьте PostgreSQL database.
5. В сервисе приложения откройте `Variables` и добавьте:
   - `BOT_TOKEN`;
   - `APP_BASE_URL` — публичный домен сервиса Railway без `/` на конце;
   - `PARENT_CHAT_IDS`;
   - `CHILD_CHAT_ID`;
   - `TIMEZONE=Europe/Berlin`;
   - `REMINDER_INTERVAL_MINUTES=7`.
6. Убедитесь, что `DATABASE_URL` доступна сервису приложения. Railway обычно прокидывает ее после подключения Postgres к проекту; при необходимости добавьте reference на переменную PostgreSQL.
7. Railway соберет приложение по `Dockerfile`. Start command задавать не нужно: он уже в Dockerfile.
8. Откройте `/health` на публичном домене. Должно быть `{"status":"ok"}`.
9. Напишите боту `/start`, затем `/today`.
10. В BotFather настройте кнопку мини-приложения на `https://ваш-домен.up.railway.app/app`.

## 5. Деплой через Railway CLI

## 6. Использование

### Основные команды

- `/start` — регистрация и показ Telegram ID.
- `/today` — расписание на сегодня.
- `/app` — открыть мини-приложение.
- `/add Название | Доза | HH:MM | Комментарий` — добавить прием.
- `/seed_schedule` — удалить старые лекарства/расписание и заново создать стартовый график из ТЗ.

Пример:

```text
/add Аквадетрим | 2 капли | 09:00 | после завтрака
```

### Как работают напоминания

1. Каждую минуту планировщик ищет просроченные и неотмеченные приемы.
2. Если прием не отмечен, бот отправляет ребенку и родителям юмористическое напоминание.
3. Повтор идет каждые `REMINDER_INTERVAL_MINUTES`, пока кто-то не нажмет `✅ Выпил(а)`.
4. После отметки родители получают сообщение о выполненном приеме.

## 7. Стартовое расписание

В проект уже внесено расписание:

- утро: Гимекромон, Тримедат за 30 минут до завтрака; Фитомуцил, Панкреатин, Баксет, Атоминекс во время еды; Аскорутин после еды;
- день: Гимекромон, Тримедат за 30 минут до обеда; Панкреатин во время еды; Аскорутин после еды;
- 17:30: Феварин;
- вечер: Гимекромон, Тримедат за 30 минут до ужина; Фитомуцил, Панкреатин во время еды; Аскорутин после еды;
- 23:15: Феварин.

Время завтрака/обеда/ужина задается переменными `DEFAULT_BREAKFAST_TIME`, `DEFAULT_LUNCH_TIME`, `DEFAULT_DINNER_TIME`. Для «сразу после еды» в MVP используется +10 минут от времени еды.

## 8. Что стоит доработать после MVP

- отдельные курсы лечения с датами начала/окончания;
- разные расписания по дням недели;
- редактирование и удаление приемов в Mini App;
- журнал комментариев по самочувствию;
- отчеты за неделю/месяц;
- режим «помощник»: если ребенок не отметил прием N минут, отправлять отдельное тревожное уведомление родителям;
- экспорт отчета врачу.
